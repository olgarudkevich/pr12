# pr12

Тестові питання до програми “Аналіз студентів”
1. Для чого використовується ifstream fin("students.txt")?
b) Щоб читати дані зі файлу

2. Чому перевіряють if (!fin) після відкриття файлу?
a) Щоб переконатися, що файл успішно відкрився

3. Для чого потрібна змінна countScholar?
c) Щоб рахувати студентів зі стипендією

4. Хто вважається стипендіатом у цій програмі?
a) Студент з балом ≥ 90

5. Яке значення змінної dorm означає, що студент живе у гуртожитку?
b) 1

6. Як обчислюється середній бал групи?
b) total / n

7. Що позначає символ ✅ у програмі?
a) Студент отримав стипендію

8. Чому потрібно закривати файли fin та fout після роботи?
a) Щоб зберегти зміни і звільнити ресурси

9. Що станеться, якщо рядок файлу містить менше п’яти елементів?
c) Програма завершиться з помилкою

10. Для чого потрібна змінна extra у цьому коді?
b) Щоб ігнорувати зайві дані у файлі

11. Чому surname і name зчитуються окремо, а не в одну змінну?
a) Щоб можна було окремо виводити прізвище та ім’я

12. Як можна змінити програму, щоб студенти у файлі відображались відсортовані за балом?
a) Додати цикл for для сортування після читання

Встанови відповідність

Команда	Призначення
ofstream	c) Запис у файл
ifstream	a) Читання файлу
fstream	d) Універсальна робота з файлом
ios::app	b) Додавання рядка в кінець
